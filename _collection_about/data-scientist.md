I develop, test and deploy quantitative Python models for markets. The typical job: take
raw data, extract what it says, and turn it into a model that raises expectancy or the
probability of success.

Most of my work is on time series: prices, volumes, spreads. I also model
multidimensional data where decisions are relative, such as options chains and portfolio
rebalancing across many assets.

## Experience
- **Financial modelling.** Profit prediction, backtesting models, trading strategies, portfolio management.
- **Risk modelling.** VaR, Monte-Carlo simulation, bootstrapping.
- **Machine learning.** Feature selection and importance, decision trees, random forests, gradient boosting (XGBoost).
- **Statistical models.** OLS, logistic regression, GARCH for volatility.
- **Optimisation.** Genetic algorithms, CMA-ES, particle swarm.
- **Data collection.** Website and REST scrapers, binary format converters, dataset cleanup and feature preparation.

## Tool set
- Python for research and production
- Cython, Numba for large computations
- MongoDB for storage
- NumPy, Pandas, SciPy
- Scikit-learn for machine learning
- Jupyter, Plotly Dash for visualisation and dashboards
